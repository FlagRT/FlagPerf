# 当前 FlagPerf 实现（CANN 9 / Torch-FL）

当前 Ascend Base INT8 Case 入口是本目录的 `main.py`。Base 正式编排入口
`base/benchmark_worker.py` 会优先选择该 vendor-specific 实现，而其他厂商继续使用上一级通用
`main.py`。

当前测量语义：

- A 为 `[M, K]` INT8，B 为 `[K, N]` INT8；
- FlagGems `scaled_mm` 使用 INT32 累加；
- `SCALE_A`、`SCALE_B` 为 FP32 标量；
- `OUTPUT_DTYPE` 默认 BF16，也可配置 FP16/FP32；
- 运算量为 `2*M*N*K*ITERS`，结果单位为 TOPS；
- Gloo 只承担 rank barrier，NPU 工作仍由 Torch-FL `flagos` 设备执行；
- Base benchmark 不包含 Oracle 测试，精度诊断由独立测试层负责。

2026-08-29 在锁定的 0.2.0/CANN 9.0.0 镜像、物理 NPU 7 的逻辑 Device 14 上，
`container_main.py` 兼容入口路由 smoke（256³、warmup 1、iterations 2）返回 rc 0；当前等价
容器 worker 已命名为 `benchmark_worker.py`。该小矩阵结果仅证明
执行和路由闭环，不是性能基线。
